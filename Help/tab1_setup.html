Setup / Generate Controls

This Tab is used to define the starting parameters for the tuning process.

Recommended workflow
  • Select f_min / f_max for your scan.(see AO Datasheet)
    For stability, consider adding a guard band around your real scan range (e.g. ±10%).
  • Choose LUT points to match how many points you will tune manually.
    (16 are usually sufficient)
  • Set Start amplitude is the level of the points in the LUT at generation (edge points are forced to 0%)
    It is always advisable to set this to start with a relatively low value (e.g. 50%) and increase gradually during tuning.
  • Pick AO model and wavelength to seed theoretical phase (beam-steer).
    This will help ensure that only small tweaks are needed during tuning.
  • Click Generate starting LUT to populate the tuning table.
